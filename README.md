# 3er Round Fit

Web del club de boxeo 3er Round Fit (Lechería, Anzoátegui).
Publicada en GitHub Pages: https://hueletayo.github.io/HuelePagWeb/

Sitio estático de una sola página: `index.html`, `style.css`, `main.js` y `assets/`.
Las inscripciones y consultas van por WhatsApp (+58 424-832 87 35).

Para probarlo en local: `python -m http.server 5500` y abrir http://localhost:5500
